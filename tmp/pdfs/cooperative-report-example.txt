นายกฤธกีรติ มานะผดุงกุล 2568: E-Leave System 
ปริญญาวิทยาศาสตรบัณฑิต (วิทยาการคอมพิวเตอร์) ภาควิชาวิทยาการคำนวณและเทคโนโลยีดิจิทัล 
อาจารย์ที่ปรึกษาโครงการ: อาจารย์พิชยภรณ์ พงศกรรังศิลป์ 
บทคัดย่อ 
 จากการปฏิบัติงานสหกิจศึกษาที่บริษัท เดฟดิว่า จำกัด ได้รับมอบหมายให้ออกแบบและพัฒนาระบบ
ให้กับบริษัท โดยออกแบบและพัฒนา E-Leave System เป็นระบบการจัดการลาในองค์กร มีวัตถุประสงค์เพื่อ
เพิ่มความรวดเร็วและความถูกต้องในการยื่นคำร้องและอนุมัติการลา ลดขั้นตอนการทำงานที่ซ้ำซ้อนจากการใช้
เอกสารกระดาษ ตลอดจนเพิ่มความโปร่งใสในการตรวจสอบข้อมูลการลา ระบบ E-Leave System ที่
พัฒนาขึ้นประกอบด้วยฟังก์ชันหลัก ได้แก่ การยื่นคำร้องลางานออนไลน์ การแจ้งเตือนผู้อนุมัติผ่านระบบหรือ
อีเมล และการคำนวณสิทธิการลาคงเหลือของพนักงานโดยอัตโนมัติ ข้อมูลทั้งหมดถูกจัดเก็บและประมวลผล
แบบเรียลไทม์ ช่วยให้ผู้บริหารและฝ่ายบุคคลสามารถติดตามสถานะการลาและประเมินปริมาณทรัพยากร
บุคคลได้อย่างมีประสิทธิภาพและตอบสนองความต้องการขององค์กรได้เป็นอย่างดี 
 โดยการปฎิบัติงานสหกิจศึกษาในครั้งนี้ ทำให้ผู้จัดทำได้รับความรู้ความเข้าใจ เกี่ยวกับการออกแบบ
และพัฒนาระบบในรูปแบบเว็บมากยิ่งขึ้น ซึ่งเป็นความรู้ที่สามารถนำไปใช้ได้จริงในการปฏิบัติงานในอนาคตได้ 
และสามารถพัฒนา E-Leave System ได้สำเร็จตามเป้าหมายที่ตั้งไว้

กิตติกรรมประกาศ 
 
 จากการปฏิบัติการงานสหกิจศึกษา ณ บริษัท เดฟดิว่า จำกัด ตั้งแต่วันที่ 25 พฤศจิกายน พ.ศ.2567 
ถึง วันที่ 14 มีนาคม พ.ศ.2568 ส่งผลให้ทางผู้จัดทำได้รับประสบการณ์ตรงในการทำงานร่วมกับองค์กรและกับ
คณะผู้จัดทำ ทำให้ได้รับประสบการณ์ตรงในการทำงานร่วมกับองค์กรและทีมงานที่มีความเชี่ยวชาญ  ซึ่ง
สามารถนำไปประยุกต์ใช้กับการทำงานในอนาคต ได้ โดยการปฏิบัติงานสหกิจศึกษาในครั้งนี้สามารถสำเร็จ
ลุล่วงได้ด้วย ความร่วมมือและการสนับสนุนจากหลายฝ่าย จึงขอขอบพระคุณ ทุกท่าน ณ ที่นี้ โดยประกอบไป
ด้วย 
 ขอขอบคุณ คุณรัฐพงศ์ ตุรงค์เรือง ตำแหน่ง กรรมการผู้จัดการ  ที่ให้โอกาสเข้ามาปฏิบัติงานภายใต้
หน่วยงานในการดูแลของ คุณรัฐพงศ์ และให้คำแนะนำในการปฏิบัติงานสหกิจศึกษา 
 ขอขอบคุณ  คุณณัฐกานต์  กวีกิจกำพล  ตำแหน่ง  ผู้จัดการ  ที่ให้โอกาสเข้ามาปฎิบัติงานภายใต้
หน่วยงานในการดูแลของ คุณณัฐกานต์ และให้คำแนะนำในการปฏิบัติงานสหกิจศึกษา 
 ขอขอบคุณ คุณยูอาคิม ดอลแสตรม ตำแหน่ง Full Stack Developer ที่ให้คำปรึกษาและแลกเปลี่ยน
ประสบการณ์ในการพัฒนาระบบ E-Leave System ตลอดช่วงระยะเวลาการปฏิบัติสหกิจศึกษา 
 ขอขอบคุณ อาจารย์ พิชยภรณ์ พงศกรรังศิลป์ อาจารย์ที่ปรึกษาโครงการสหกิจศึกษา แนะนำการ
ปฏิบัติงานและตรวจสอบระบบตลอดถึงการแก้รายงานโครงการสหกิจศึกษาฉบับนี้ให้สำเร็จลุล่วงไปได้ 
 สุดท้ายขอกราบขอบคุณ ครอบครัวและผู้ให้คำปรึกษา ที่สนับสนุนและให้กำลังใจในทุกเรื่อง ที่ทำให้
สามารถทำโครงการสหกิจศึกษาและรายงานฉบับนี้จนสำเร็จลุล่วงไปได้ด้วยดี

1. React 
 React เป็นไลบรารีจาวาสคริปต์และเป็นซอฟต์แวร์เสรีและโอเพนซอร์ส ซึ่งมีจุดประสงค์เพื่อไว้สำหรับ
สร้างส่วนต่อประสานกับผู้ใช้โดยอาศัยส่วนประกอบต่าง  ๆ ที่สามารถทำงานร่วมกันได้อย่างลงตัวและไร้
รอยต่อ พัฒนาโดยMeta (เดิมชื่อ Facebook) อีกทั้งยังมีชุมชนซึ่งประกอบด้วยนักพัฒนาและบริษัทจำนวน
มาก React สามารถใช้ในการพัฒนาโปรแกรมประยุกต์แบบหน้าเดียว  โปรแกรมประยุกต์สำหรับอุปกรณ์
เคลื่อนที่ และโปรแกรมประยุกต์ที่แสดงผลผ่านเซิร์ฟเวอร์ได้โดยอาศัยเฟรมเวิร์ก เช่น  เน็กซ์เจเอส  และ
เนื่องจากรีแอ็กต์นั้นเกี่ยวข้องเฉพาะส่วนต่อประสานกับผู้ใช้และการเร็นเดอร์ส่วนประกอบต่าง  ๆ ในด็
อม โปรแกรมประยุกต์รีแอ็ กต์จึงมักจะพึ่งพาไลบรารีต่าง  ๆ สำหรับการจัดเส้นทางและฟังก์ชันด้านไคลเอนต์
อื่น ๆ โดยข้อดีที่สำคัญอย่างหนึ่งของรีแอ็กต์คือ รีแอ็กต์จะทำการเร็นเดอร์หน้าเดิมใหม่เฉพาะส่วนที่มีการ
เปลี่ยนแปลงเท่านั้น ทำให้ไม่ต้องเร็นเดอร์ใหม่ในส่วนที่ไม่ได้มีการเปลี่ยนแปลง รีแอ็กต์เปิดตัวครั้งแรกเมื่อ 29 
พฤษภาคม พ.ศ. 2556 [1] 
2. Postman  
 Postman เป็นเครื่องมือทดสอบที่ช่วยให้นักพัฒนาแอปฯ สามารถสร้าง ทดสอบ และแก้ไข API ได้ 
ซึ่งอินเทอร์เฟซผู้ใช้ของเครื่องมือทดสอบ API นี้ช่วยให้ developer และ QA สามารถส่ง HTTP request และ
ติดตามการตอบสนองได้อย่างง่ายดาย  ด้วยเครื่องมือทดสอบ Postman คุณจะสามารถเข้าถึงชุดเครื่องมือที่
ครอบคลุมซึ่งช่วยเร่งวงจรการใช้งาน API ได้อย่างครบวงจร ตั้งแต่การออกแบบ การทดสอบ ไปจนถึงเอกสาร
ประกอบและการทำต้นแบบ [2] 
3. pgAdmin 
   pgAdmin  เป็นโปรแกรมที่ใช้ในการจัดการระบบฐานข้อมูลและการพัฒนา  Open Source  ที่
หลากหลาย สำหรับ  PostgreSQL  โดยโปรแกรมที่ใช้ PostgreSQL เป็นฐานข้อมูล เช่น phpBB, Joomla,

1. ศึกษาระบบงานเดิมและแนวทางในการพัฒนาระบบ 
 จากการศึกษาพบว่า ระบบงานเดิมมักใช้เอกสารกระดาษหรือวิธีการบันทึกข้อมูลด้วยมือในการยื่นคำ
ร้องและอนุมัติการลา ซึ่งส่งผลให้เกิดปัญหาดังนี้ 
- การประมวลผลคำร้องลาช้าและไม่เป็นระบบ 
- การคำนวณสิทธิการลาที่อาจผิดพลาดเนื่องจากพึ่งพาการคำนวณด้วยมือ 
- การจัดเก็บข้อมูลที่ไม่มีระบบ ข้อมูลการลาอาจถูกเก็บในรูปแบบที่ไม่สามารถสืบค้นหรือวิเคราะห์ได้
ง่าย 
- การเก็บข้อมูลด้วยเอกสารกระดาษอาจเสี่ยงต่อการสูญหายหรือถูกเข้าถึงโดยไม่ได้รับอนุญาต

Purpose: เพื่อให้ผู้ใช้งานสามารถตั้งค่ารหัสผ่านใหม่ได้ในกรณีที่ลืมรหัสผ่าน หรือผู้ดูแล
ต้องการรีเซ็ตรหัสผ่านให้ผู้ใช้งาน 
Pre-Conditions: ผู้ใช้งานหรือผู้ดูแลต้องมีบัญชีผู้ใช้ในระบบแล้ว 
Post-Conditions: ผู้ใช้งานมีรหัสผ่านใหม่ที่สามารถใช้งานได้ 
Main Flow: 1. ผู้ใช้งานคลิกปุ่ม “ลืมรหัสผ่าน” หรือ ผู้ดูแลเข้าสู่เมนูจัดการผู้ใช้แล้วเลือกรี
เซ็ตรหัสผ่าน 
2. ระบบขอให้ระบุอีเมลหรือเลือกบัญชีผู้ใช้ที่ต้องการรีเซ็ตรหัสผ่าน 
3. ระบบส่งอีเมลหรือลิงก์รีเซ็ตรหัสผ่านไปยังอีเมลของผู้ใช้ (หรือผู้ดูแลกำหนด
รหัสผ่านใหม่ให้ได้โดยตรง) 
4. ผู้ใช้งานคลิกลิงก์ในอีเมลหรือกรอกรหัสผ่านใหม่ตามที่ผู้ดูแลกำหนด 
5. ระบบตรวจสอบความถูกต้องของลิงก์/โทเค็นรีเซ็ต (ถ้ามี) และบันทึก
รหัสผ่านใหม่ลงในฐานข้อมูล 
6. ระบบแจ้งเตือนผู้ใช้งานว่าได้ทำการเปลี่ยนรหัสผ่านสำเร็จ 
Alternate Condition: 1. หากผู้ใช้งานไม่ได้รับอีเมลหรือลิงก์รีเซ็ตรหัสผ่าน 
2. หากโทเค็นรีเซ็ตรหัสผ่านหมดอายุหรือไม่ถูกต้อง

Post-Conditions: 1. บัญชีผู้ใช้ถูกสร้าง, ลบ หรือแก้ไขข้อมูลเรียบร้อย 
2. สิทธิ์หรือบทบาทของผู้ใช้เปลี่ยนแปลงตามที่ผู้ดูแลกำหนด 
Main Flow: 1. ผู้ดูแลเข้าหน้า “จัดการบัญชีผู้ใช้” 
2. ระบบดึงรายการผู้ใช้ทั้งหมดจากฐานข้อมูล 
3. ผู้ดูแลสามารถเลือกผู้ใช้ที่ต้องการแก้ไขข้อมูล หรือกด “เพิ่มผู้ใช้ใหม่” 
4. ผู้ดูแลกรอกหรือแก้ไขข้อมูลผู้ใช้ 
5. ระบบบันทึกข้อมูลลงฐานข้อมูลและแสดงรายการอัปเดต 
Alternate Condition: ข้อมูลที่กรอกไม่ถูกต้องหรือซ้ำกัน

ผลการดำเนินงาน

ระบบมี 2 ระดับ คือ ผู้ดูแลระบบและผู้ใช้งาน โดยที่ผู้ใช้แต่ละระดับสามารถดำเนินการได้ดังต่อไปนี้ 
   1. สิทธิในการเข้าใช้งานของผู้ดูแลระบบ 
 - เข้าสู่ระบบด้วย อีเมล และ รหัสผ่าน 
 - สามารถเพิ่ม/ลบ/แก้ไขบัญชีผู้ใช้ เช่น สร้างผู้ใช้ใหม่ กำหนดสิทธิการเข้าถึง 
 - สามารถกำหนดประเภทการลา และกำหนดเงื่อนไขหรือข้อกำหนดต่าง ๆ

สรุปผลการปฏิบัติงาน ปัญหา ประโยชน์ที่ได้รับ และข้อเสนอแนะ 
1. สรุปผลการดำเนินงาน 
 ในระหว่างการปฏิบัติงานสหกิจศึกษา ณ บริษัท เดฟดิว่า จำกัด ทำให้ผู้จัดทำ ได้รับประสบการณ์ใน
การทำงานมากขึ้นและได้เรียนรู้สิ่งใหม่ที่ไม่เคยรู้มาก่อน และได้นำความรู้ในวิชาเรียนมาประยุกต์ใช้การทำงาน 
ในการจัดการ หรือวางแผนงานอย่างเป็นระบบ นอกจากนี้ยังได้รับประสบก ารณ์การทำงานจริงรวมไปถึงการ
ทำงานเป็นทีม ซึ่งผู้จัดจะนำประสบการณ์ในครั้งนี้ไปปรับใช้เพื่อพัฒนาหรือ ปรับปรุงตนเองในการทำงานใน
อนาคต 
2. ปัญหาและอุปสรรคบางประการ 
 เนื่องจากความรู้และประสบการณ์ยังไม่เพียงพอจึงต้องทำการ ศึกษาเพิ่มเติม ทำใ ห้การออกแบบและ 
พัฒนาระบบในช่วงแรกเกิดความล่าช้า ต่อมาเมื่อได้ทำการศึกษาและได้รับคำแนะทางพี่จากหน่วยงานจึงทำให้
ออกแบบและพัฒนาระบบได้ดีขึ้นตามลำดับ 
3. ประโยชน์ที่ได้รับ 
3.1 ด้านหน่วยงาน 
- เกิดความร่วมมือระหว่างหน่วยงานและมหาวิทยาลัย  
- ทางหน่วยงานได้ระบบที่หลากหลายและมีความสวยงามมากยิ่งขึ้น  
- ได้ระบบที่สามารถทำการลาอิเล็กทรอนิกส์ 
- หน่วยงานสามารถนำกระบนการด้านสหกิจศึกษามาคัดเลือกพนักงานที่จะเข้ามาทำงานใน 
 หน่วยงานได้ดียิ่งขึ้น 
 3.2 ด้านมหาวิทยาลัย 
- เพื่อให้ทางมหาวิทยาลัยได้รับข้อมูลกลับมาปรับปรุงพัฒนาหลักสูตรการเรียนการสอนให้ดียิ่งขึ้น  
- เกิดคามร่วมมือกันทางวิชาการและความสัมพันธ์กับหน่วยงาน 
 3.3 ด้านนิสิตผู้ปฏิบัติงาน 
 - ได้ใช้ความรู้ที่เรียนมาประยุกต์ใช้ในการปฏิบัติสหกิจศึกษา

- ได้ทักษะและประสบการณ์ในวิชาชีพตามสาขาที่เรียน ที่เพิ่มเติมจากภายในห้องเรียน

- การออกแบบและพัฒนาระบบนั้น ควรมีข้อมูลเอกสารที่เป็นลายลักษณ์อักษร เพื่อให้ผู้พัฒนาระบบ
