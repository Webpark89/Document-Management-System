P91: 1. ที่มาและความสำคัญ
P92: การจัดการเอกสารด้วยไฟล์และขั้นตอนอนุมัติที่แยกจากกันทำให้ผู้เกี่ยวข้องค้นหาเอกสาร ติดตามสถานะ และตรวจสอบประวัติการเปลี่ยนแปลงได้ยาก เอกสารความต้องการของบริษัท นิสซุย (ประเทศไทย) จำกัด จึงกำหนดให้มีระบบกลางสำหรับสร้าง จัดเก็บ ค้นหา และอนุมัติเอกสารอิเล็กทรอนิกส์ พร้อมควบคุมสิทธิ์และเก็บประวัติการใช้งาน
P93: โครงการ Document Management System (DMS) พัฒนาเป็นเว็บแอปพลิเคชันสำหรับ เอกสารคำขอซื้อ (PR) ใบสั่งซื้อ (PO) บันทึกข้อความ (BK) และ PDF ทั่วไป ผู้ใช้สามารถจัดทำร่าง ส่งอนุมัติ ติดตามผล และเรียกดูเวอร์ชันย้อนหลังได้ภายในระบบเดียว

P272: 3. การประเมินการใช้งาน
P273: ระบบ DMS ช่วยรวมงานสร้าง จัดเก็บ อนุมัติ และติดตามเอกสารไว้ในจุดเดียว ผู้ใช้สามารถค้นหาข้อมูลตามประเภท สถานะ และผู้เกี่ยวข้อง ขณะที่ผู้ดูแลระบบกำหนดข้อมูลหลักและลำดับอนุมัติได้จากหน้าจัดการ การจัดเก็บเวอร์ชันและประวัติการกระทำช่วยให้ตรวจสอบเส้นทางของเอกสารได้ชัดเจน
P274: บทที่ 5
P275: สรุปผลการปฏิบัติงาน ประโยชน์ที่ได้รับ และข้อเสนอแนะ
P276: 1. สรุปผลการดำเนินงาน
P277: การปฏิบัติงานสหกิจศึกษาระหว่างวันที่ 22 มิถุนายน – 16 ตุลาคม 2569 ได้พัฒนาระบบ DMS สำหรับจัดการเอกสารหลายประเภทและกระบวนการอนุมัติ โดยมีโครงสร้างฐานข้อมูล หน้าจอ และ API รองรับการสร้างเอกสาร การส่งอนุมัติ การติดตามสถานะ และการเรียกดูประวัติย้อนหลัง
P278: 2. ผลสำเร็จตามวัตถุประสงค์
P279: ระบบรวมข้อมูลเอกสารไว้ในศูนย์กลางเดียว รองรับแบบฟอร์มและ PDF พร้อมเลขเอกสารและเวอร์ชัน กำหนดผู้อนุมัติเป็นลำดับ แสดงสถานะงาน และจัดเก็บข้อมูลสำหรับตรวจสอบย้อนหลัง ผลงานที่ส่งมอบประกอบด้วยซอร์สโค้ด โครงสร้างฐานข้อมูล ภาพหน้าจอ และคู่มืออธิบายกระบวนการหลัก
P280: 3. ประโยชน์ที่ได้รับ
P281: 3.1 ด้านหน่วยงาน
P282: หน่วยงานได้ระบบกลางสำหรับจัดการเอกสารและลำดับอนุมัติ ช่วยให้ค้นหา ติดตามสถานะ และตรวจสอบประวัติเอกสารได้สะดวกขึ้น
P283: 3.2 ด้านมหาวิทยาลัย
P284: รายงานแสดงการประยุกต์ความรู้ด้านการวิเคราะห์ระบบ ฐานข้อมูล เว็บแอปพลิเคชัน และการทดสอบซอฟต์แวร์กับงานองค์กร
P285: 3.3 ด้านนิสิต
P286: ผู้จัดทำได้ฝึกวิเคราะห์ความต้องการ ออกแบบฐานข้อมูลและลำดับงาน พัฒนาส่วนหน้าและ API และจัดทำเอกสารสรุปผลการพัฒนาอย่างเป็นระบบ
P287: 4. ข้อเสนอแนะ
P288: - เพิ่มการค้นหาแบบเต็มข้อความเพื่อช่วยค้นเนื้อหาในเอกสารจำนวนมาก
P289: - พัฒนารายงานสรุประยะเวลาการอนุมัติและปริมาณเอกสารรายประเภท
P290: - เพิ่มการแจ้งเตือนผ่านช่องทางที่เหมาะกับการใช้งานขององค์กร
P291: - ขยายรูปแบบเอกสารและแม่แบบให้รองรับหน่วยงานอื่น
P292: - กำหนดรอบทบทวนสิทธิ์และสำรองข้อมูลอย่างสม่ำเสมอ
